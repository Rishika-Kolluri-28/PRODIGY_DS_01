
# Prodigy InfoTech - Data Science Internship

## Task 01: Data Visualization

### Objective
Create a histogram and bar chart to visualize population distribution using the World Bank population dataset.

### Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Visual Studio Code

### Dataset
World Bank Population Dataset:
https://data.worldbank.org/indicator/SP.POP.TOTL

### Visualizations
1. Population Distribution Histogram
2. Top 10 Most Populated Countries Bar Chart

### How to Run

Install the required libraries:

pip install pandas matplotlib seaborn

Run the Python program:

python task1.py

### Output
- population_histogram.png
- population_bar_chart.png
